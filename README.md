# 🌧️ Rainfall Pattern Analysis & Prediction

An interactive data analytics and machine learning application for exploring rainfall patterns across India, understanding historical rainfall trends, and predicting rainfall using data-driven models.

Built with Python, Streamlit, Pandas, Scikit-learn, and Plotly, this project transforms historical rainfall data into meaningful visualizations and interactive analytical tools.

## 📌 Project Overview

Rainfall plays a crucial role in agriculture, water resource management, disaster preparedness, and environmental planning. Analyzing historical rainfall patterns helps us understand seasonal variations, regional differences, and long-term trends.

This project provides an interactive platform to explore rainfall data, visualize patterns, investigate datasets, and experiment with machine learning models for rainfall prediction.

## 🚀 Getting Started

Follow these steps to run the application locally.

### 1. Prerequisites

Install Python 3.10 or later and Git.

Verify your Python installation:

```bash
python --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/Lovepreetsingh2006/Rainfall-pattern.git
```

Navigate into the project directory:

```bash
cd Rainfall-pattern
```

### 3. Create a Virtual Environment

**Windows:**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can run the following command for the current terminal session:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Then activate the environment again.

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install Dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Run the Application

Start the main Streamlit application:

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:8501
```

## 🧪 Run Tests

Run the project's automated tests using:

```bash
pytest
```

For more detailed test output:

```bash
pytest -v
```
